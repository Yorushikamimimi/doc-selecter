# 文件整理助手技术边界

本文保留实现中引用的主要契约编号，不含私有开发过程记录。

## §2.4 移动

macOS 使用 `RENAME_EXCL` 原子不覆盖移动；不可用则拒绝，不降级为覆盖。跨卷跳过。

## §3 分类

先排除受保护项，再按扩展名分类。最长扩展名优先，模糊格式进入待确认。名称和项目标记保护为启发式，不读取正文，不保证识别所有隐私或成套资源。

## §5.1.1 计划指纹

计划使用规范化编码生成指纹，绑定来源、目标、选择范围、规则与文件身份；执行需要对应确认。

## §5.3.1 执行核验

移动前核对路径、每级父目录与文件身份；不得通过日志恢复扩大原确认范围。

## §5.3.2.1 / §5.3.3 日志

执行、撤销持久化 intent/result 并逐条同步，锁防止并发。损坏日志拒绝继续；恢复不改写旧代次证据或重设原身份基准。

## §5.4 / §5.4.1 撤销

撤销依赖文件身份、原位置可用性和状态记录。成功后再次核对原位置身份，外部改动可能阻止完整撤销。

## §5.5 / §5.5.3 身份

身份核对包含 dev、inode、大小、mtime_ns 与类型；不跟随链接，快照不等于文件内容备份。

## §5.6.3 目录归档

条件归档默认关闭，仅处理本批授权且因整理变空的目录；普通预先为空的目录走独立剩余项入口。归档不删除目录。外部写入竞态仍存在，异常保留现场。

## §7.2 / §7.3 恢复与边界

状态、计划、确认与日志留在本机。恢复不得以当前观测覆盖原身份基准；状态缺失、外部替换或位置占用可能阻止还原。不承诺断电／内核崩溃时的目录持久性。

## §8.2 测试

只在人工沙盒中验证。后台子集、GUI 自动化、原生人工验收和用户体验反馈分别记录，不相互替代。
